🔍 Azure OpenAI Configuration Help

Your Current Configuration:

The API route expects these environment variables:

AZURE_OPENAI_ENDPOINT=https://haveo-mjvf43tr-eastus2.services.ai.azure.com
AZURE_OPENAI_IMAGE_DEPLOYMENT=gpt-image-1
AZURE_OPENAI_API_KEY=FAD...
AZURE_OPENAI_API_VERSION=2025-04-01-preview

📝 How to Find the Correct Deployment Name:

  1. Go to Azure Portal
  2. Navigate to your Azure OpenAI resource: haveo-mjvf43tr-eastus2
  3. Click on "Model deployments" or "Deployments" in the left menu
  4. Find the DALL-E deployment name (it might be different from "gpt-image-1")
  5. Common names: dall-e-3, dalle3, image-gen, dall-e
  6. Update AZURE_OPENAI_IMAGE_DEPLOYMENT in your .env.local file
